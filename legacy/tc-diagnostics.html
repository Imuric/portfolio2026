Thyrocare Franchise Portal

Modernizing a 15-year-old legacy system while preserving user muscle memory and trust.

Client Thyrocare
Role Lead Designer
Type B2B SaaS

The Problem

Franchisees were using a portal built over a decade ago. It was cluttered, slow, and non-responsive. Operators had developed "tribal workarounds" and resisted any change that threatened their existing habits.

User Habit

"I can navigate the old portal with my eyes closed. If you move the 'Print Report' button, I won't be able to work."

Intelligent Information Architecture

Rebuilt the IA to group related tasks while keeping core actions exactly where users expected them to be.

  • Consolidated reporting
  • Real-time order status
  • Simplified financial reconciliation

Impact & Outcomes

🚀

86% Adoption in 6 Weeks

High user acceptance rate despite the drastic visual overhaul.

💰

22% Lower Cost-per-report

Improved efficiencies in data entry and processing reduced operational costs.
